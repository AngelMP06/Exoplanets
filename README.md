This project generates a dashboard from the data of exoplanets from NASA

# Columnas eliminadas

pl_masse eliminada — más del 60% de nulos. Se usa pl_rade en su lugar, que además es el criterio estándar para clasificar tipos de planetas.

st_spectype — más del 50% de nulos se calculará con la temperatura de la estrella.

st_rotp, , st_age eliminadas — más del 50% de nulos sin valor real para el dashboard.
